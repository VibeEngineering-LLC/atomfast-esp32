Node-скрипт без фреймворка, в стиле `tests/web/store-clear.test.js`: `const assert = require('assert'); const path = require('path'); const S = require(process.env.HC_MODULE || path.join(__dirname, '..', '..', 'web', 'push-model.js'));`, счётчики `passed/total`, функция `check(name, fn)` печатает `ok  <имя>` или `FAIL <имя>: <сообщение>`, в конце `console.log('TESTS: ' + passed + '/' + total)` и `process.exit(passed === total ? 0 : 1)`. ## Проверки (имена дословно)
1. `порт: 0, 65536, 70000, abc, пусто, -1 отклоняются; 1, 8480, 65535 принимаются` — для плохих `validateForm(F({port:x}), true)`: `ok === false` и `field === 'pushPort'`; для хороших `ok === true` и `body.port` равен числу.
2. `адрес: пустой при включённой отправке -> ошибка pushHost` — `F({host:''})` и `F({host:'   '})`; `ok false`, field `pushHost`, error `Укажите адрес приёмника`.
3. `адрес: пустой при выключенной отправке допустим` — `F({enabled:false, host:''})` ok true, `body.host === ''`.
4. `адрес: допустимы IPv4 и имя; недопустимы 256.1.1.1, 1.2.3, a..b, -a.b, a_b.lan, пробел внутри, 64 символа` — хорошие: `192.0.2.10`, `db.lan`, `raspi5-home.local`; плохие из списка (64 символа — `'a'.repeat(64)`) дают ok false, field `pushHost`.
5. `токен: не показывается в теле, если поле пустое` — `F({token:''})` с `tokenSet=true`: у `body` нет ключа `token` и нет `clear_token`.
6. `токен: ввод кладётся в тело как есть` — `body.token === 'tok_AbC123-xyz'`; другие ключи тела только `enabled, host, port` (проверить `Object.keys(body).sort()` равно `['enabled','host','port','token']`).
7. `токен: пробел, кавычка, обратная косая и 65 символов отклоняются` — `'a b'`, `'a"b'`, `'a\\b'`, `'x'.repeat(65)` -> ok false, field `pushToken`; `'x'.repeat(64)` допустим.
8. `токен: включение без токена и без сохранённого -> ошибка pushToken` — `F({token:''})` с `tokenSet=false`: ok false, field `pushToken`, error `Укажите токен приёмника`.
9. `очистка токена: флаг кладёт clear_token, вместе с вводом токена запрещён` — `F({token:'', clearToken:true, enabled:false})` с `tokenSet=true`: ok true, `body.clear_token === true`, нет `token`; `F({clearToken:true})` (токен введён) -> ok false, field `pushTokenClear`.
10. `очистка токена при включённой отправке запрещена` — `F({token:'', clearToken:true})`, `tokenSet=true` -> ok false, field `pushTokenClear`.
11. `tokenHint: задан / не задан` по `WORKING` и `LIVE`.
12. `stateText: все состояния и остановка по токену` — off, idle, sending, error, `{state:'weird'}`, `{}`, `null`, и `Object.assign({}, WORKING, {auth_stop:true})` -> строка с `отклонил токен`.
