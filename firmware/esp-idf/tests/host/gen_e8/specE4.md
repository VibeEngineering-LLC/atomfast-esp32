## Что тестируется
`int af_push_send_ring(const af_push_ops_t *ops, void *ctx, int kind, const af_push_cfg_t *c, const char *mac, af_push_ring_t *r, uint8_t *auth_stop, char *body, size_t cap, uint32_t *pending_left, int *cursor_moved)` (возвращает AF_PUSH_S_OK=0/IDLE=1/WAIT=2/STOP=3; размер пачки = min(r->eff_batch ? r->eff_batch : c->batch_rows, c->batch_rows); в заголовке X-AF-First-Seq (в тесте это FK.last_first_seq) стоит seq ПЕРВОЙ ЗАПИСАННОЙ В ТЕЛО строки, а не начало плана; если запись по plan.start нечитаема и пропущена, first_seq больше)), `af_push_json(char *buf, size_t cap, const af_push_cfg_t *c, const af_push_view_t *v)`, поля `af_push_cfg_t` (host[64], token[65], port, interval_s, batch_rows, timeout_s, rings, enabled), `af_push_ring_t` (cur{acked,epoch,valid}, err, stopped, fails, eff_batch, sent_total ...), `af_push_ring_init(r, batch)`, `AF_PUSH_ERR_NET=1`.

## Тесты (имена обязательны)
1. `t_send_read_timeout` — fk_reset; st_init(&ST,1300,400,400); st_fill(&ST,200,0,0); ST.rbusy=1; c=gcfg(50); r=af_push_ring_init(50); send1(0,...) → S_WAIT; FK.calls==0; moved==0; r.cur.valid==0; r.err==0; r.fails==0. Затем ST.rbusy=0 → S_OK и FK.calls==1.
2. `t_send_batch_clamp` — fk_reset; st_fill raw 300; c=gcfg(50); r.eff_batch вручную установить в 500 (после af_push_ring_init(&r,500)); send1 → S_OK; body_lines(FK.last_body)-1 == 50 (размер ограничен настройкой, а не eff_batch); r.cur.acked==49.
3. `t_send_first_seq_skips` — fk_reset; st_fill raw 20; испортить CRC записи seq=0 (`ST.buf[0][18] ^= 0xFF`); c=gcfg(50); send1 → S_OK; FK.last_first_seq==1; строка 1 тела начинается с `D1_MAC ",1,21,"` (проверь strncmp с длиной 24: "02:af:00:00:00:01,1,21," — 17+1+1+1+2+1 = 23 символа; используй strlen литерала); r.cur.acked==19 (auto_ok ответ по последней строке тела); r.sent_total==19.
4. `t_json_size_max` — максимально длинный вывод: c = gcfg(2000); host из 63 символов 'a'; token из 64 символов 'x'; port=65535; interval_s=3600; timeout_s=30; rings=7; v=mkview(); для i=0..2: v.info[i]={present 1, oldest 4000000000u, head 4294967295u, epoch 4294967295u}; v.ring[i].cur={4000000000u, 4294967295u, 1}; v.ring[i].err=10; v.ring[i].last_http=999; v.ring[i].sent_total=v.ring[i].fail_total=v.ring[i].retries=4294967295u; v.ring[i].last_rows=65535; v.ring[i].last_ok_ts=4294967295u; v.ring[i].stopped=1; v.now_ts=4294967295u; v.stack_hwm=4294967295u; v.test={2, 999, 4294967295u, 2147483647, 10, 4294967295u}; n=af_push_json(OUT, sizeof OUT, &c, &v): n>0; n < 2048 (потому что прошивка выделяет под JSON 2048 байт); выведи в CHECK также n < 1900 как запас 7%.
5. `t_json_public_name` — c=gcfg(500); v=mkview(); host "af.local" (имя): JSON содержит подстроку `"public_addr":false`; host "8.8.8.8": содержит `"public_addr":true`; host "10.1.2.3": `"public_addr":false`; host "172.32.0.1": `"public_addr":true`. (Используй strstr по OUT.)
