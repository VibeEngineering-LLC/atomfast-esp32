## Что напечатать
Вспомогательная локальная функция (static, перед sec8_send) `static int send_one(const char *tag, int kind, const af_push_cfg_t *c, af_push_ring_t *r, uint8_t *auth, int *calls_total)` ВОЗВРАЩАЕТ rc (результат af_push_send_ring) и вызывает `af_push_send_ring(&FK_OPS, &FK, kind, c, D1_MAC, r, auth, BODY, sizeof BODY, &left, &moved)` (left — uint32_t, moved — int, оба обнулить до вызова) и печатает строку:
`printf("send %s k=%d rc=%d mv=%d left=%lu acked=%lu v=%u calls=%d first=%lu lost=%lu epoch=%lu len=%lu crc=%08lx err=%u stop=%u eff=%u\n", tag, kind, rc, moved, (unsigned long)left, (unsigned long)r->cur.acked, (unsigned)r->cur.valid, FK.calls, (unsigned long)FK.last_first_seq, (unsigned long)FK.last_lost, (unsigned long)FK.last_epoch, (unsigned long)FK.last_len, h32(FK.last_body, FK.last_len), (unsigned)r->err, (unsigned)r->stopped, (unsigned)r->eff_batch);` и делает `(*calls_total)++`, затем `return rc;`. Во всех сценариях rc берётся из возврата send_one; af_push_send_ring напрямую в sec8_send НЕ вызывай. Пиши только код, без рассуждений в комментариях (комментарий — одна короткая строка на сценарий).
Подготовка в каждом сценарии: `memset(&FK, 0, sizeof FK); FK.st = &ST; FK.http = 200; FK.auto_ok = 1; FK.now = 1792860000; st_init(&ST, 1300, 400, 400); st_fill(&ST, 1200, 365, 291); af_push_cfg_default(&c); c.enabled = 1; c.batch_rows = 100; for k: af_push_ring_init(&r[k], 100); uint8_t auth = 0;`
Сценарии (тег — первая буква):
(а) «a»: раунды по 0..99: для k=0..2 вызвать send_one; запоминать rc каждого; прервать, когда за раунд все три вернули IDLE (rc==1). Печатаются все вызовы.
(б) «b» с неисправностями: заново подготовить; счётчик общих вызовов calls_total с 0; перед каждым вызовом send_one: если calls_total+1 == 3 → FK.http = 503; ==5 → FK.transport = 1; ==8 → FK.http = 413; иначе FK.http = 200 и FK.transport = 0 (сбрасывать перед каждым вызовом); раундами по k=0..2 до 60 вызовов или пока все три IDLE.
(в) «c» 401: заново подготовить; FK.http = 401; один вызов send_one(k=0); затем FK.http = 200 и ещё один вызов send_one(k=0) (в нём ничего особенного — кольцо не помечено остановленным при 401).
(г) «d» повтор после сброса: заново подготовить; выполнить полную отправку кольца 0 (вызывать send_one(k=0) в цикле до rc==1, не больше 40 вызовов), затем `af_push_ring_reset_cursor(&r[0], 100); strcpy(FK.resp, "{\"accepted\":0,\"last_seq\":1199}");` и один вызов send_one(k=0), ещё один вызов send_one(k=0) с FK.resp = "" (пустым).
(д) «e» нечитаемые записи: заново подготовить; st_init(&ST,1300,400,400); st_fill(&ST,30,0,0); испортить CRC записей seq=0 и seq=7: `ST.buf[0][0*AF_REC_RAW_SIZE+18] ^= 0xFF; ST.buf[0][7*AF_REC_RAW_SIZE+18] ^= 0xFF;` затем вызовы send_one(k=0) до rc==1 (не больше 10).
Все вызовы печатают строки, образцов должно получиться около сотни.
