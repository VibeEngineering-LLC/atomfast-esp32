## Что тестируется (из af_push.h; не объявляй заново)
Тип `af_push_cfg_t {uint8_t enabled; uint8_t rings; uint16_t port, interval_s, batch_rows; uint8_t timeout_s; char host[64]; char token[65];}`, `af_push_cmd_t {af_push_cfg_t cfg; uint8_t token_changed; uint8_t dest_changed;}`; макросы AF_PUSH_E_BODY=-1, E_JSON=-2, E_KEY=-3, E_VALUE=-4, E_INCOMPLETE=-5; AF_PUSH_CFG_BLOB=152. Функции: `void af_push_cfg_default(af_push_cfg_t*)` (enabled 0, rings 7, port 8480, interval_s 60, batch_rows 500, timeout_s 8, host и token пустые), `int af_push_host_ok(const char*)` (1/0), `int af_push_token_ok(const char*)`, `int af_push_addr_class(const char*)` (0 публичный IPv4, 1 частный/локальный IPv4, 2 имя или не IPv4), `int af_push_cfg_valid(const af_push_cfg_t*)` (0 или AF_PUSH_E_VALUE), `int af_push_cfg_complete(const af_push_cfg_t*)` (1/0), `int af_push_parse(const char *body, size_t n, const af_push_cfg_t *cur, af_push_cmd_t *cmd)` (0 или код ошибки), `size_t af_push_cfg_encode(const af_push_cfg_t*, uint8_t *buf, size_t cap)` (152 или 0), `bool af_push_cfg_decode(af_push_cfg_t*, const uint8_t *buf, size_t len)`, `uint32_t af_bsn_crc32(const uint8_t*, size_t)`.
Правила: host — [A-Za-z0-9.-], длина 1..63, первый и последний символ буква/цифра, нет "..", строка из одних цифр и точек должна быть корректным IPv4 (4 октета 0..255, без ведущих нулей). Токен — длина 1..64, символы 0x21..0x7E кроме `\` и `"`. Раскладка blob: 0..3 'A','P','S','1'; 4..5 = 1,0; 6..7 = 0x8C,0x00; 8 enabled; 9 rings; 10..11 port (младший первым); 12..13 interval_s; 14..15 batch_rows; 16 timeout_s; 17 резерв 0; 18..81 host (64 байта); 82..146 token (65 байт); 147 резерв 0; 148..151 CRC32 (af_bsn_crc32 по байтам 0..147, младший первым).

## Вспомогательные функции внутри файла (напиши сам; static)
- `static af_push_cfg_t good_cfg(void)` — default, затем enabled=1, host="10.1.2.3", token="tok-0123456789abcdef", port=8480, rings=7.
- `static void fix_crc(uint8_t b[152])` — пересчитать и записать CRC в b[148..151] (младший первым) через af_bsn_crc32(b,148).
- `static int parse_s(const char *s, const af_push_cfg_t *cur, af_push_cmd_t *cmd)` — `return af_push_parse(s, strlen(s), cur, cmd);`.
