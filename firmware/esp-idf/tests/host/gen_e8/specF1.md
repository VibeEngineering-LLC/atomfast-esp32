## Готовые модули (не переписывай; используй)
1. `listen` — модуль HTTP-слушателя (файл listen.py лежит в каталоге из переменной окружения `AF_LISTEN_DIR`). Содержит: `class Handler(BaseHTTPRequestHandler)` с методами `do_GET`, `do_POST`, `_send(self, status: int, payload: dict)` (шлёт JSON-ответ, при необходимости сначала дочитывает тело; ставит `self.close_connection = True`), атрибутами экземпляра `self.headers`, `self.path`, `self.rfile`, `self.server` (у сервера: `token`, `ingest`, `db`, `max_body`, `db_lock`), `class IngestServer(ThreadingHTTPServer)`, функцию `make_server(host, port, token, ingest, db, max_body=65536) -> IngestServer` (token не короче 16 символов; host не wildcard). `IngestServer.__init__` обращается к имени `Handler` как к глобальному в модуле listen, поэтому подмену обработчика делай присваиванием `listen.Handler = MyHandler` ДО вызова make_server.
2. `af_collector` — пакет в каталоге из переменной окружения `AF_SCRIPTS_DIR` (в ней лежит подкаталог af_collector): `from af_collector.push import ingest_batch` (сигнатура `ingest_batch(db, mac, ring, epoch, first_seq, lost, csv_text, *, use_ext=True) -> (accepted, last_seq)`, где ring — число 0/1/2; `ingest_batch` бросает ValueError при неверной пачке) и `from af_collector.memdb import MemoryDb` (хранилище в памяти; публичные атрибуты: `rows: dict[(hwid, ring, gen, seq) -> строка]`, `cursors`, `import_log: list[dict]`, `hardware`).
3. В listen слушатель вызывает `server.ingest(server.db, mac, ring_name, epoch, first_seq, lost, csv_text)` где ring_name — строка "raw"/"agg"/"env". Нужна обёртка `ingest(db, mac, ring_name, epoch, first_seq, lost, csv_text)`, которая переводит имя кольца в число (`{"raw": 0, "agg": 1, "env": 2}`) и вызывает `ingest_batch(db, mac, ring_num, epoch, first_seq, lost, csv_text)`.

## Что должен делать эмулятор
Запуск: `python3 emu_receiver.py --port N --token T` (порт и токен обязательны; хост всегда 127.0.0.1). Перед обращением к модулям: `sys.path.insert(0, os.environ["AF_LISTEN_DIR"])` и `sys.path.insert(0, os.environ["AF_SCRIPTS_DIR"])`; если переменных нет — напечатать ошибку в stderr и выйти с кодом 2. После `make_server` напечатать в stdout строку `READY` (flush=True) и запустить `serve_forever()`; по `KeyboardInterrupt` или команде /ctl/stop остановиться (для остановки из обработчика запускай `threading.Thread(target=server.shutdown).start()`).

Класс `EmuHandler(listen.Handler)` с переопределением методов:
- Общее состояние — атрибуты класса (общие на все запросы): `posts: list[dict]` (журнал POST /ingest/*), `faults: list[dict]` (очередь неисправностей, FIFO), `lock = threading.Lock()` для журнала и очереди.
- Переопределённый `_send(self, status, payload)`: если у экземпляра `self._suppress` истинно — ничего не отправлять, только `self.close_connection = True` и вернуть; иначе запомнить `self._last = (status, payload)` и вызвать `super()._send(status, payload)`.
- `do_GET(self)`: путь `/ctl/stats` (только если `self.client_address[0] == "127.0.0.1"`) → отправить JSON статистики (формат ниже) через `listen.Handler._send` с кодом 200; иначе `super().do_GET()`.
- `do_POST(self)`: 
  а) если путь начинается с `/ctl/` (и клиент 127.0.0.1): разобрать `urllib.parse.urlsplit(self.path)` и `parse_qs`; команды: `/ctl/fault?kind=K&n=N[&code=C]` — добавить в очередь N раз элемент `{"kind": K, "code": C}` (K = `code` — ответить кодом C, не трогая БД; `drop` — прочитать тело и закрыть соединение без ответа, ничего не записывая; `commit_drop` — выполнить настоящую обработку (запись в БД), но ответ не отправлять, соединение закрыть); `/ctl/token?v=V` — `self.server.token = V`; `/ctl/maxbody?v=N` — `self.server.max_body = int(N)`; `/ctl/reset_db` — `self.server.db = MemoryDb()` и очистить журнал posts; `/ctl/stop` — остановить сервер (поток с shutdown). Все команды отвечают `{"ok": true}` с кодом 200 (через `listen.Handler._send`; тело запроса у команд пустое, но `_send` дочитает Content-Length, если он есть).
  б) путь `/ingest/<ring>`: взять из очереди одну неисправность, если очередь не пуста (под lock). Определить `ring` из пути, `first_seq` из заголовка `X-AF-First-Seq` (целое или None), `length` из Content-Length (или 0). 
     - kind == `code`: `self._send(code, {"error": "injected"})`; запись в журнал {ring, first_seq, status: code, inj: true}.
     - kind == `drop`: прочитать `length` байт тела (если length>0), `self.close_connection = True`, запись в журнал {ring, first_seq, status: 0, inj: true}, вернуть без ответа.
     - kind == `commit_drop`: `self._suppress = True`, вызвать `super().do_POST()`, затем запись в журнал {ring, first_seq, status: 0, inj: true, committed: статус из self._last (или None)}, и `self.close_connection = True`.
     - нет неисправности: `self._suppress = False`; вызвать `super().do_POST()`; затем по `self._last` (может не быть, если `super().do_POST()` вернулся без вызова `_send` — тогда статус 0) записать в журнал {ring, first_seq, status, accepted, last_seq (из payload, если это 200), inj: false, len: length}.
  Перед обработкой каждого запроса инициализируй `self._suppress = False; self._last = None` (в `do_POST` и `do_GET`).
- Статистика `/ctl/stats` (JSON, ключи): `posts` — копия журнала; `rows` — `{"raw": n, "agg": n, "env": n}` где n — число ключей в `server.db.rows` с соответствующим номером кольца (ключ — кортеж (hwid, ring, gen, seq), ring числом 0/1/2); `max_seq` и `min_seq` — по тем же ключам максимум и минимум seq на кольцо (или -1, если строк нет); `accepted_sum` — сумма поля accepted по записям журнала со статусом 200 и inj == false, по кольцам; `hardware` — число записей в `server.db.hardware`.
- Журнал и статистика не содержат токена и заголовка Authorization.

`main()` — разбор аргументов `argparse` (`--port` int, `--token` str), создание `MemoryDb()`, `listen.Handler = EmuHandler`, `server = listen.make_server("127.0.0.1", port, token, ingest, db)`; вызвать как `if __name__ == "__main__": raise SystemExit(main())`.
