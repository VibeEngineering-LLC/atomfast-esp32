    Подтверждение

    Обновление через плату

    Плата сама обращается к GitHub, скачивает образ, сверяет SHA-256 по файлу SHA256SUMS.txt и записывает его в запасной раздел. Браузер с GitHub не общается. Автоматической проверки нет: запрос только по кнопке.

    РелизСостояниеЗаметки

    Установка

    Запасной путь: через браузер

    Если плата сама не доходит до GitHub: страница получает список релизов, скачивает образ, проверяет его и заливает на плату. По умолчанию выключено.

    Список релизов GitHub в браузере

    Запросы к GitHub идут из этого браузера, плата в них не участвует. Автоматической проверки нет: список запрашивается только по кнопке «Проверить».

    Установка

    Ручная заливка файла .bin

    Файл проверяется до отправки: размер и первый байт образа (0xE9). Плата сама сверяет сегменты и откатывается на прежнюю прошивку при ошибке.

    Обслуживание

    Переподключение заново запускает связь с дозиметром по BLE. Перезагрузка прерывает связь с платой примерно на 10 секунд.

    Погрешность измерений

    Складывается со статистической (Пуассон, по выбранному k·σ) квадратично и влияет на значения в «Показаниях» и в сводке под графиком. Пустое поле: систематическая часть не учитывается.

    Интерфейс

    Размер шрифта
    Применяется ко всем страницам сразу, хранится в этом браузере.

    Цвета графиков

    Цвет ряда общий для линии на графике, легенды, подписи оси и статистики под графиком; сглаженная линия берёт цвет ряда. Цвета хранятся в этом браузере отдельно для светлой и тёмной темы. Недоступны цвета, у которых контраст к фону графика ниже 3:1.
