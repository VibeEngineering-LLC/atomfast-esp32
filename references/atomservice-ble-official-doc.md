## Что подтверждено документом
- **Основная характеристика** `70BC767E-7A1A-4304-81ED-14B9AF54F7BD` (Notification, каждые 2 с), 13 байт little-endian: флаги u8; накопленная доза float (в документе mSv); мощность дозы float µSv/h (окно N = 34 с по умолчанию); импульсов за последние 2 с u16; заряд батареи i8, %; температура i8, °C. Скрипт `atom-fast-zabbix.py` разбирает так же (флаги, 2 float, u16, i8, u8).
- **Флаги:** бит 0 — превышен порог дозы или мощности дозы; бит 1 — сбрасываемый флаг превышения порога мощности дозы; бит 2 — за 2 с скорость счёта изменилась более чем на X стандартных отклонений (по умолчанию 5), мощность дозы пересчитывается заново; бит 3 — **зарезервирован**; бит 4 — превышение тока через детектор; бит 5 — перегрузка детектора (мёртвое время > 50 %, поправка > 2); бит 6 — подключено зарядное; бит 7 — аварийное выключение.
- **Дополнительная характеристика** `8E26EDC8-A1E9-4C06-9BD0-97B97E7B3FB9` (Read, 20 байт): u64 общее число импульсов; u32 импульсы коррекции на мёртвое время; u32 импульсов за N с; u32 время измерения дозы, с. Нужна для пересчёта дозы за обрыв связи без потери точности float.
- **Калибровка** `57F7031F-03C1-4016-8749-BAABAA58612D` (18 байт, запись с паролем в RAM): чувствительность имп/мкР (СБМ-20: 78), фон (1/15 имп/с), мёртвое время 0,2 мс, время расчёта мощности дозы 34 с (чётное). **Не трогать** (калибровка прибора).
- **Управление** `EA50CFCD-AC4A-4A48-BF0E-879E548AE157` (8 байт: команда, три параметра u16, флаги): 0x0A «тихий» режим, 0x10 снять «тихий», 0x11 подтвердить и снять сбрасываемые флаги, 0xAA мелодия поиска, 0xCA сохранить настройки во флеш (пароль), 0xDE сброс накопленной дозы (пароль), 0xFF выключить питание (пароль). Пороги — три характеристики по 10 байт (`3F71E820…`, `2E95D467…`, `F8DE242F…`); текстовое имя — `BB6C9C06…` (20 символов); служебная — `E2423A67…`.
- **Без подключения:** имя в эфире обновляется каждые 2 с строкой `AtomTag: x.xxx uSv/h` (20 символов, Latin-1); MANUFACTURER_SPECIFIC — 4 байта: флаги, заряд %, температура °C, версия прошивка+железо (единицы как в основной характеристике).
- **Формулы:** коррекция мёртвого времени N = M / (1 − M·T) для секунд, где M > 100 имп; МАЭД = ((ΣN)·K1/n)·3600 − K2 (отрицательное — показывать 0); статистическая погрешность D = Kp·√(ΣN)·100 %, Kp = 1 / 2 / 3 для доверия 67 / 95 / 99 %; D = N/K [мкР], D = N/(114·K) [мкЗв]; поисковый режим суммирует секунды назад до ΣN ≥ F (10 / 20 / 30), не более 100 с; измерительный режим — результат с тремя значащими цифрами.

## Расхождения с нашим разбором (проверить, не править без проверки)
1. У нас `valFlags` бит 3 = «re-read config request» (`atomfast-onair-protocol.md:53`); документ называет бит 3 зарезервированным. Источник нашего значения — эфир, не документ; сверить на живых пакетах.
2. Дополнительная характеристика `8E26EDC8…` у нас «назначение TBD». По документу это счётчики импульсов (u64/u32/u32/u32): можно читать для точного счёта за обрыв связи.
3. Документ не называет единицу накопленной дозы однозначно (mSv); наша интерпретация единицы — проверить по прибору.
4. Погрешность замера: документ задаёт D = Kp·√N·100 % с Kp = 1, 2, 3; в e16g коэффициент покрытия не показывался — уточнить, какой Kp использует расчёт «± %» (TODO T-69).
5. Пассивное чтение дозы по имени и MANUFACTURER_SPECIFIC без подключения (экономия BLE-соединения, один клиент GATT) — возможная функция, не проверена на нашем приборе.
